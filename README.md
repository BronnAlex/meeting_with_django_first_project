# Описание
Проект интернет-магазина catalog

Данный проект  будем дорабатывать на каждом уроке в течение всего курса. 
Можно отправить на данный момент форму с данными 
Установил django 
Добавил файл зависимостей pip freeze > requirements.txt
Создал Директорию templates и в ней два html шаблона
Настроил файл настройки в config, добавил созданное приложение catalog
STATICFILES_DIRS =(BASE_DIR / 'static',) Добавил данную конфигурацию
Создал файл .gitignore и добавил туда всю конфигурацию по лучшим практикам
Создал и реализовал файл путей в приложении catalog/urls.py
 Реализовал контроллеры. А также контроллер на POST запрос в файле catalog/views.py
